# 通信条件付きSnapshot Diff（2026-10-04）

Protocol・Portを指定した比較に、条件付きMatrix / Pathの既存評価器を使用する。条件未指定時は従来の設定概要。通信差分には前後の判定と根拠、応答全体には評価方式と適用条件を含める。

Policy・Network差分は条件によらず全件を比較する。PARTIAL・UNKNOWN・NO_ROUTEを新規拒否と混同しない。Portだけ指定した場合はTCP / UDP / SCTPを評価する。入力値の検証はMatrixと共通化し、portは0〜65535。UIでは条件を明示適用し、旧リクエストを中断して古い結果の上書きを防ぐ。

## 制約

通信評価はSegment全体、新規通信、送信元port未指定。全Segmentの組み合わせを解析するため、大規模構成は時間がかかる場合がある。実機セッションの検証や稼働環境への反映は行っていない。
